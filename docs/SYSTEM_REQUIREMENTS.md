## AIアシスタントへの指示

## 1. システム概要

### 1.1 目的
1. **稼働報告の可視化**: LINEからの報告をGAS経由でスプレッドシートに蓄積し、未報告者やフォーマットエラーをリアルタイムで検知・一覧化する。
2. **報酬の予実突合**: 自社が提出した「シフト予定表（Excel）」と、上位店から送られてくる「支払通知書（Excel）」の2ファイルをアップロードして自動で突き合わせ、報酬の漏れや代走（イレギュラー）を人間がパズル感覚で確認・確定できるようにする。

### 1.2 技術スタック
- **フロントエンド**: React, TypeScript, Vite
- **スタイリング**: Vanilla CSS (Tailwindは使用せず、既存のモダンなGlassmorphismデザインを踏襲)
- **アイコン**: `lucide-react`
- **Excel解析**: `xlsx` (SheetJS)

## 2. 機能要件

### 機能①：ダッシュボード（リアルタイム報告管理）
GASの `doGet` APIからJSONでスプレッドシートのデータを取得し、表示する。

1. **全体サマリー表示**
   - 選択された日付の「稼働台数」「報告完了数」「未報告アラート数」をパネル表示。
2. **一覧リスト表示**
   - ドライバーごとに「コード名」「コマ数（A/B/AB）」「報告状態」をカード形式で表示。
   - 報告済みの場合は「配達件数」と「稼働者名（申告）」を表示。
3. **エラー詳細の動的表示（A列検知）**
   - スプレッドシートのA列（エラー詳細）に値がある場合、赤文字の警告アイコンと共にその理由を表示する。空欄の場合は「※配達件数がまだ報告されていません」をデフォルトで表示。
4. **絞り込み・フィルター**
   - 日付ピッカーによる日別絞り込み（デフォルトは本日）。
   - コマ数（すべて / A / B / AB）でのフィルター、「未報告のみ表示」のトグルスイッチ。

### 機能②：シフト予実突合（2つのExcel比較による報酬チェック）
ダッシュボード画面から「予実突合」モードに切り替え、2つのExcelファイルをブラウザ上で解析し、結果を照合する。

1. **ファイルアップロード（2ファイル入力）**
   - **① 自社提出シフト予定 (`shift_template_*.xlsx`)**
     - 対象シート：左から2番目（インデックス1）
     - 取得項目：「日付」「フルネーム」「ブロック（稼働コマ）」
   - **② 上位店からの実績 (`代理店支払通知書_*.xlsx`)**
     - 対象シート：左から2番目（サマリーシート・インデックス1）
     - 取得項目：「日付」「ドライバー（漢字フルネーム）」「件数」
   - *※注意: Excelのヘッダーは1行目とは限らないため、配列として読み込み「日付」「ドライバー/フルネーム」などの文字列が含まれる行を探してパースすること。*
2. **データクレンジングと照合ロジック**
   - 名前から空白（スペース）を削除して正規化して比較する（例：「北脇 郁也」→「北脇郁也」）。
   - Excel内のシリアル値の日付は `YYYY-MM-DD` 形式に変換し、日付ごとにグループ化して比較する。
3. **照合結果のUI（代走・漏れチェックパネル）**
   - 日付ごとに結果をセレクトボックス等で切り替え表示。
   - **完全一致**: 両方に名前があり、件数も一致している人。
   - **件数不一致**: 両方に名前があるが、件数が異なる人（差異件数をハイライト表示）。
   - **左右比較パネル（パズルUI）**:
     - **左側（上位店のみに存在）**: 支払通知書にはあるが、自社シフトにいない。（例：〇〇さん 20件）
     - **右側（自社シフトのみに存在）**: 自社シフトにはいるが、支払通知書にいない。（例：▽▽さん 6件、□□さん 14件）
     - ※この左右パネルを見比べることで、管理者が「あ、右の2人が左の人の代走だな」と人間が目視で計算・確定できるUIを提供する。

## 3. 既存のGAS API仕様（ダッシュボード用）
- **エンドポイント**: `https://script.google.com/macros/s/AKfycbwAMsW-5Jir6SkJ6VykJvxt2KKO6PP6S3mqNAv1JBl8K9v6leDWYNebcj26mcASmZOKqw/exec`
- **リクエスト**: `?month=2026年8月` (GET)
- **レスポンス (JSON)**:
  ```json
  {
    "sheetName": "2026年8月",
    "data": [
      {
        "エラー詳細": "フォーマットエラー",
        "日付": "2026-08-01T15:00:00.000Z",
        "コマ数": "A",
        "コード名": "北脇郁也",
        "稼働者(申告)": "北脇郁也",
        "配達件数": "",
        "受託率": 90,
        "配達完了率": 90
      }
    ]
  }
  ```
- **仕様**: 1行目がヘッダーキーとなる。A列（エラー詳細）が空欄の場合はJSONのキーとして出力されないか、空文字となる場合がある。日付はUTCで返るため、フロントエンドでJSTへのパースが必要。
