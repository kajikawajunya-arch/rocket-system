# プロジェクト引継ぎ書（ロケットナウ報告管理ダッシュボード）

## 1. プロジェクトの現状（完了していること）
* **フロントエンド**: React (Vite) + TypeScript でダッシュボードUIを構築完了。
* **バックエンド（GAS）**: Google Sheets API を通じて最新の稼働データをJSONで取得するAPI連携が完了。
* **公開環境**: GitHubリポジトリ（`rocket-system`）と連携し、**Vercel にてインターネット公開（デプロイ）済み**。
* **主な機能**:
  * 日付選択カレンダー（選択した日付の稼働データを表示）
  * コマ数フィルター（Aコマ、Bコマ、AB通し）
  * **未報告者のみの絞り込みフィルター**
  * GASからのデータを利用した「報告済 / 未報告」のアラート表示
  * **動的エラー詳細表示**：スプレッドシートの「A列（エラー詳細）」を読み取り、UI上にフォーマットエラー等の具体的な理由を赤文字で表示する機能（実装済み、テスト待ち）
